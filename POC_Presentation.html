Slide 4 • End-to-End Flowchart (Main Focus)

How Our App Works: Live Pipeline Flowchart

Step-by-step dataflow from mouse hover to fully generated Visual C++ resource script.

1
Trigger & Hook
User activates global hotkey Ctrl+Shift+H. Win32 global hook engages and floating pill overlay appears.
2
Hover Detection
Mouse cursor hovers over target app control. System extracts internal text:
UIA (Primary)
0ms Direct Read
OCR (Fallback)
Media OCR
3
Deduplication
In-memory filter suppresses repeated hovers. Automatically maps string to compliant identifier:
IDS_BTN_EXPORT
4
Review & Template
DataGrid updates in real time. Items merge into 2dTransRes.rc template with STRINGTABLE blocks.
5
Validate & Export
Built-in parser performs 1-click syntax check. Generates clean .rc file ready for Visual Studio.
